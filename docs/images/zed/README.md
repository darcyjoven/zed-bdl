# Zed 手册素材

使用手册里的 `📷` / `🎬` 占位块对应下表中的文件。拍好后放到本目录，
在 `docs/USER-GUIDE.md` 里把占位块替换成 `![说明](images/zed/文件名)` 即可。

| 文件 | 类型 | 建议内容 |
|---|---|---|
| `01-install.png` | 截图 | `zed: install dev extension` 选择本目录 |
| `02-settings.png` | 截图 | `settings.json` 里的 `lsp.bdl-lsp` 配置 |
| `03-diagnostics.png` | 截图 | 打开 `.4gl` 后的诊断面板 |
| `04-hover.gif` | 录屏 | 悬停变量显示来源 |
| `05-completion.gif` | 录屏 | 补全与函数签名 |
| `06-format.gif` | 录屏 | 格式化前后 |
| `07-deploy-task.png` | 截图 | `task: spawn` 列表与部署输出 |
| `08-link-status.png` | 截图 | 终端里的 `bdl-lsp link status` |

素材要求同 VSCode 手册：不要出现真实主机、账号、密码和客户代码。
